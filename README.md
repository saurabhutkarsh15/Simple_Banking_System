# SIMPLE BANKING SYSTEM

## Problem Statement :- 
Create a banking application that allows customers to open an account, deposit, withdraw, transfer money, and check their balance, with all data stored in a file.

## Project Overview :-
The Simple Banking Sysytem is console based banking application developed using Python 3. It allows usres to create account, deposit money, withdraw money, transfer money between accounts, check balances.
All account information is stored in a file, provding data persistance between program executions.

## Technologies Used :-
    1. Python 3
    2. JSON
    3. File Handling
    4. Git and GitHub

## Concepts Used :-
    1. Functions
    2. Loops
    3. Conditional Statements
    4. Exception Handling
    5. File Handling
    6. JSON 
    7. Input Validation

## Project Requirements :-
    - Account Number starts from 1001.
    - A minimum balance of Rs. 500 must always remain.
    - Account information is used in bank.txt

## How to Run this Project :-
    1. Install Python 3.
    2. Clone or download this repository.
    3. Open this on VS Code.
    4. Run using the command given below in the terminal :-> python banking.py
